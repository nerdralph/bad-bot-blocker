# bad-bot-blocker
block bad bots benignly for Apache on Linux

Alpha prototype for testing.

The intention of this project is a transparent bad bot blocker for Apache.  Transparent means invisible to human browsers and friendly bots like Googlebot.

crawler_check.py is a rewrite map that validates crawlers like Googlebot and bingbot via reverse-forward DNS checks.  It has been stable and bug free since October 2026.

This software is developed and tested on https://solarsi.ca
